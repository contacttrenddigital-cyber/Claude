# Make One Exception – анимирано лого

Логото е на кампанията на Renew Europe „Make One Exception“, която призовава Child Guarantee да бъде финансирана.

| Файл | За какво е |
|---|---|
| `make-one-exception-animated.svg` | За уебсайт. Векторно е, с прозрачен фон, около 77 KB. Пуска се веднъж и спира на финалното лого. Вгражда се с `<img src="make-one-exception-animated.svg">`. |
| `make-one-exception-animated.mp4` | За социални мрежи и презентации. 1920×1080, 60 fps, 3,9 s, бял фон. |
| `make-one-exception-animated.gif` | За имейли и чатове. 960×425, 25 fps, повтаря се. |

## Сценарий на анимацията (≈2,4 s + задържане)
1. **0,05–0,8 s:** „MAKE ONE“ се плъзга нагоре буква по буква.
2. **0,45–1,85 s:** „EXCEPTION“ се изписва черта по черта като с флумастер, в реда, в който пише дете. Всяка буква леко подскача, когато е готова.
3. **1,7–2,4 s:** „renew europe.“ изплува отдолу, а точката „пуква“ последна.

Ако потребителят е избрал намалено движение (`prefers-reduced-motion`), SVG файлът показва директно готовото лого.

`src/` съдържа скриптовете, с които е генерирано всичко: извличане от PDF, изчисляване на чертите, сглобяване на SVG и рендериране на кадри.
