# Фактчек: Радев и „петото място“ по икономически ръст

Вертикално видео (1080×1920, 30 кадъра/сек., H.264 + AAC, ~44 сек.), изградено с Remotion, React и TypeScript.

## Готови файлове

- `output/factcheck-radev-eurostat-2026.mp4` — крайното видео
- `output/factcheck-radev-poster.png` — корица

## Команди

```bash
npm install
npm run studio     # преглед и редакция в Remotion Studio
npm run render     # output/factcheck-radev-eurostat-2026.mp4
npm run poster     # output/factcheck-radev-poster.png
npm run sfx        # пресъздава звуковите ефекти с FFmpeg
npm run typecheck
```

Ако Remotion не може сам да свали браузър, посочете готов:
`REMOTION_BROWSER=/път/до/chrome-headless-shell npm run render`

## Използвани материали

- **Видео и звук на изказването:** предоставеният файл (`.MOV`, HEVC, 7,47 сек.), прекодиран без промяна на съдържанието в `public/radev-original.mp4` (H.264), за да се чете от браузъра на Remotion. Използвана е цялата му дължина с оригиналния звук; върху него няма диктор, музика или ефекти. Цветовете на записа не са променяни (палитрата черно/бяло/червено важи за графиките).
- **Субтитри:** времената са от автоматична транскрипция (Whisper) на самия запис, уточнени по паузите в звука. В записа се чува точно: „Ние сме пети в целия Европейски съюз за третото тримесечие по икономически ръст.“
- **Шрифт:** Inter (SIL Open Font License), вграден в `public/fonts`.
- **Звукови ефекти:** собствени, синтезирани с FFmpeg (`scripts/make-sfx.sh`). Няма музика и няма външни записи.

## Ограничения

1. **Няма диктор.** В средата няма настроена услуга за български синтез на реч, затова видеото е монтирано така, че да е напълно разбираемо само с екранния текст. Текст за запис:
   - Сцена 3: „Според Евростат пред България са не четири, а пет държави. Ирландия и Полша — 3,6%. Кипър — 3,1%. Швеция — 2,8%. Испания — 2,7%. И чак след тях — България с 2,5%.“
   - Сцена 4: „България е шеста, а не пета сред държавите с публикувани данни.“
   - Сцена 5: „В Европейския съюз има 27 държави, но към момента на проверката са публикувани данни само за 20. Класирането може да се промени.“
   - Сцена 6: „Икономическият ръст е реален. Но шесто място от двайсет не е пето от двайсет и седем.“

   За да добавите запис: сложете файла в `public/` и добавете `<Audio src={staticFile('…')} />` в `<Sequence from={ranking}>` във `src/Video.tsx`; при нужда коригирайте кадрите в `src/timing.ts` и `ROW_STARTS` в `Ranking.tsx`.
2. **Проверка на данните.** Потвърдени от публични източници са: самото изказване (БТА, 16.11.2026 г.) и годишният растеж за ЕС от +1,5% (Евростат, 13.11.2026 г.). Стойностите по държави (3,6 / 3,6 / 3,1 / 2,8 / 2,7 / 2,5%) и броят „20 от 27“ **не можаха да бъдат проверени независимо** — сайтът на Евростат не е достъпен от средата за рендериране. Използвани са точно както са подадени. Преди публикуване ги сверете с таблицата на Евростат и се уверете, че са за растеж спрямо същото тримесечие на предходната година.
3. **Произход на клипа.** Метаданните на предоставения файл показват, че е преминал през инструмент за обработка (`DreaminaMetaInfo`, `te_is_reencode`, енкодер Lavf). Това само по себе си не означава, че записът е променен, но автентичността му не може да се установи от файла. Препоръчително е да се свери с официалния запис от заседанието на Министерския съвет.
4. **„ЛЪЖА“ срещу „ПОДВЕЖДАЩО“.** Надписът „ЛЪЖА“ е драматичен преход по задание; редакционната оценка във финала е „ПОДВЕЖДАЩО“. Видеото не твърди умисъл.
