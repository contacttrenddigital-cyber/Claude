  Инструменти (проверени): `search`, `fetch`, `list_datasets`, `describe_dataset`, `get_data`, `explain_number`, `about_data`.
- **Отворени файлове**: `https://sigma-budget.midt.bg/data/<slug>.json`, всеки с `meta` блок.
- Издание към проверката: `dataVersion 2026-11-18.1`, 31 набора / 76 файла / 0 mock, последен месечен отчет КФП 2026-09-30, следващ 2026-10-31.
