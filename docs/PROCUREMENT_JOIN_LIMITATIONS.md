# Договори и плащания: ограничения

**Статус: изградено (без свързване с бюджетни редове).** `/dogovori`: подписаните договори от отворените данни на ЦАИС ЕОП (Агенция по обществени поръчки) за януари–октомври 2026 г. — по месец, възложител (по ЕИК/БУЛСТАТ), дейност и вид процедура, и 300-те най-големи договора. Данни: `npm run sources:procurement` (файлове на storage.eop.bg, изброени на https://app.eop.bg/today/reporting/open-data), модул `src/lib/procurement/contracts.ts`.

## Защо договорите не са свързани с бюджетните програми
- Отворените данни на ЦАИС ЕОП са достъпни (проверено 22.11.2026). Вътрешният API на системата не се ползва: изисква вход и не е документиран.
- В официалните ни източници няма списък с ЕИК/БУЛСТАТ на 45-те първостепенни разпоредители, а свързване само по име не правим.
- Бюджетните редове (функции, тавани, проекти) и поръчките нямат общ публикуван идентификатор. Изключение са номерата на приоритетните проекти (NP-…), но те още не са свързани с поръчки.

## Как ще се свързва
1. Ключове: ЕИК на възложителя, номер на проект (NP-…), уникален номер на поръчката. Никога само по име.
2. Всяко свързване се записва с източник и ниво на увереност (точен ключ, съвпадение по име, ръчно потвърдено).
3. Етапи: предложено → прието → договорено → платено. Липсващ етап се показва като липсващ, не като нула.
4. Без изводи за нарушения. Разминаванията се показват като въпроси с право на отговор.
